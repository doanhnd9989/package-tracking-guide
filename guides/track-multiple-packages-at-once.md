# How to Track Multiple Packages at Once (Bulk Tracking)

> Canonical version: https://www.24htrack.com/blog/track-multiple-packages-at-once

Checking parcels one by one on each carrier's website stops working at around ten shipments. Online sellers, dropshippers and small logistics teams need one list that covers every carrier and updates itself.

## Short answer

Use a multi-carrier tracker that accepts lists. On 24hTrack you can paste several numbers on the homepage for a quick check, or save them to an account where they update automatically: add up to 40 at a time, import an Excel or CSV file of up to 50,000 rows, or sync a Google Sheet so statuses are written back into your spreadsheet, free. Developers can use the REST API or webhooks.

## What a good bulk tracker should do

- Detect the carrier for each number automatically, because a list mixes carriers.
- Convert every carrier's wording into the same small set of statuses so you can filter, for example, all "Exception" parcels.
- Keep the full scan history, not just the latest status.
- Export to Excel or CSV, and sync to the spreadsheet you already use.
- Alert you when something changes, so you do not have to check.
